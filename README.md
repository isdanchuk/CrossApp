# CrossApp

Наскрізний навчальний проєкт з дисципліни «Крос-платформне програмування».

## Предметна область
* **Назва:** Бібліотека
* **Сутності (DTO):** `BookDto` (видання), `ReaderDto` (читач), `ImportResult<T>` (результат розбору даних).
* **Призначення:** Облік видачі примірників книг читачам, толерантний імпорт даних із зовнішніх файлів.

## Структура рішення (після Лабораторної №3)
* `data/`
  * `sample.csv` — тестові дані каталогу книг (містить 11 коректних рядків та 3 навмисно пошкоджені рядки).
* `src/Core/` — спільна бібліотека логіки:
  * `Dto/` — незмінні `record`-типи для представлення даних (`BookDto`, `ReaderDto`, `ImportResult<T>`).
  * `Import/` — логіка імпорту та толерантного розбору (`BookCsvImporter`).
  * `Domain/` — каталог для доменної моделі (наступний етап).
  * `Storage/` — каталог для сховищ даних (наступний етап).
* `src/Cli/` — консольна точка входу (`Program.cs`: валідація шляху, виклик імпортера, форматований вивід результату й помилок).

## Формат вхідного файлу CSV
* **Шлях за замовчуванням:** `data/sample.csv`
* **Кодування:** UTF-8
* **Роздільник:** `;` (крапка з комою — запобігає конфліктам із комами в назвах чи авторах)
* **Заголовок:** присутній (`id;isbn;title;year;author`), автоматично ігнорується парсером
* **Колонки:** 
  1. `Id` (рядок, наприклад `B-001`)
  2. `Isbn` (рядок, обов'язковий)
  3. `Title` (назва книги, обов'язкова)
  4. `Year` (рік видання, ціле число 1450..поточний рік)
  5. `Author` (автор книги, необов'язкове поле)

## Збірка та запуск
```bash
# Збірка всього рішення
dotnet build

# Запуск імпорту файлу за замовчуванням (data/sample.csv)
dotnet run --project src/Cli

# Запуск з явним зазначенням шляху до файлу
dotnet run --project src/Cli -- data/sample.csv

# CrossApp

Наскрізний навчальний проєкт з дисципліни «Крос-платформне програмування».

## Предметна область
* **Назва:** Бібліотека
* **Сутності:** Book (видання), BookCopy (примірник), Reader (читач), Loan (видача).
* **Призначення:** Облік видачі примірників книг читачам та контроль їх повернення.

## Структура рішення (після Лабораторної №2)
* `src/Core/` — бібліотека класів (спільна логіка, збір системних даних, моделі).
  * `Dto/` — record-типи передачі даних.
  * `Domain/` — сутності предметної області з інваріантами.
  * `Storage/` — сховища та взаємодія з базою даних.
* `src/Cli/` — консольна точка входу (лише форматування виводу та запуск).

## Збірка та запуск
```bash
# Збірка всього рішення
dotnet build

# Запуск консольного застосунку
dotnet run --project src/Cli

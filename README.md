# CrossApp

Наскрізний навчальний проєкт з дисципліни «Крос-платформне програмування».

## Предметна область
* **Назва:** Бібліотека
* **Головна сутність:** `Book` (видання з інваріантами та станом примірників `TotalCopies` / `AvailableCopies`).
* **DTO зберігання:** `BookDto` (незмінний `record` для серіалізації у JSON).
* **Призначення:** Облік видань бібліотеки, видача та повернення примірників читачам.

## Архітектура та Dependency Injection (Лабораторна робота №5)

### Контракт та реалізації
* **Інтерфейс сховища (`IBookStore`):**
  * `List()` — повертає `IReadOnlyList<Book>` для захисту колекції від зовнішніх мутацій.
  * `GetById(string id)` — пошук книги за ідентифікатором (повертає `Book?`).
  * `Find(Func<Book, bool> predicate)` — фільтрація записів за довільним предикатом.
  * `Add(Book item)` — додавання нової книги з перевіркою унікальності `Id`.
  * `Update(Book item)` — збереження оновленого стану книги після видачі/повернення.
  * `Remove(string id)` — видалення запису зі сховища.
* **Реалізації сховища:**
  * `InMemoryBookStore` — зберігає дані у `Dictionary<string, Book>` в оперативній пам'яті (ініціалізується через `SampleData`). Після завершення програми дані очищуються.
  * `FileBookStore` — зберігає дані у JSON-файлі (`data/library.json` у каталозі запуску `AppContext.BaseDirectory`) через мапінг у `BookDto`. Використовує ліниве завантаження (`EnsureLoaded`) та миттєвий запис на диск (`Flush`) при кожній зміні.
  * `CachingBookStore` *(Декоратор)* — обгортає будь-яку реалізацію `IBookStore` та кешує результати запитів `GetById` у пам'яті з інвалідацією при змінах.
* **Бізнес-сервіс (`LendingService`):** працює виключно через абстракцію `IBookStore` (операції `AddBook`, `IssueCopy`, `ReturnCopy`, `AllBooks`, `FindById`, `SearchByAuthor`) і не залежить від способу зберігання даних.

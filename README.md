# CrossApp

Наскрізний навчальний проєкт з дисципліни «Крос-платформне програмування»[cite: 18].

## Предметна область
* **Назва:** Бібліотека[cite: 10, 18]
* **Сутності (DTO):** `BookDto` (видання), `ReaderDto` (читач), `ImportResult<T>`, `MixedImportResult`[cite: 1, 10].
* **Призначення:** Облік бібліотечного фонду та видачі книг, толерантний імпорт каталогів із файлів[cite: 1, 18].

## Структура рішення (після Лабораторної №3)
* `data/`
  * `sample.csv` — каталог книг із навмисно пошкодженими рядками[cite: 1, 3].
  * `sample.json` — дані у форматі JSON.
  * `mixed.csv` — файл зі змішаними даними (книги та читачі)[cite: 14].
* `src/Core/` — бібліотека логіки:
  * `Dto/` — незмінні `record`-типи для представлення даних[cite: 1, 2].
  * `Import/` — імпортери (`BookCsvImporter`, `BookJsonImporter`, `MixedCsvImporter`)[cite: 1, 14].
  * `Domain/` — зарезервовано під доменну модель (лабораторна 4)[cite: 1, 18].
  * `Storage/` — зарезервовано під сховища даних (лабораторна 5)[cite: 1, 18].
* `src/Cli/` — точка входу (обробка аргументів, запуск імпорту, вивід таблиці та статистики)[cite: 1, 6, 14].

## Формат файлів імпорту
* **Роздільник CSV:** `;` (крапка з комою, щоб уникнути конфліктів із комами в назвах)[cite: 4, 13].
* **Кодування:** UTF-8[cite: 13].
* **Заголовок:** присутній (`id;isbn;title;year;author`), ігнорується парсером автоматично[cite: 4, 11].
* **Змішаний імпорт:** визначається за префіксом рядка (`B` — книга, `R` — читач)[cite: 14].

## Збірка та запуск
```bash
# Збірка всього проєкту
dotnet build

# Імпорт основного CSV-файлу (за замовчуванням)
dotnet run --project src/Cli

# Імпорт JSON-файлу
dotnet run --project src/Cli -- data/sample.json

# Імпорт змішаного файлу з префіксами B/R
dotnet run --project src/Cli -- data/mixed.csv

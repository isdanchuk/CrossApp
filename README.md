# CrossApp

Наскрізний навчальний проєкт з дисципліни «Крос-платформне програмування».

## Предметна область
* **Назва:** Бібліотека
* **Сутності:** Book (видання), BookCopy (примірник), Reader (читач), Loan (видача).
* **Призначення:** Облік видач примірників книг читачам та їх повернення.

## Запуск застосунку
```bash
dotnet build
dotnet run --project src/Cli
